## 1. 系統概覽

本系統是一套基於 LINE 的甜點預購平台，分為兩個部分：

| 部分 | 對象 | 入口 |
|------|------|------|
| 後台管理 | 店家人員 | `https://ditto-cake.vercel.app/admin` |
| 訂購頁面 | 顧客 | LINE LIFF 連結 |

**核心功能**
- 建立開單批次（限時限量預購）
- 顧客透過 LINE 直接下單
- 後台追蹤訂單狀態、確認付款
- 多人員協作，依角色分配操作權限

## 2. 初次設定說明

### 2.1 系統設定

進入後台 → **系統設定** 頁面，填寫以下資訊：

| 設定項目 | 說明 |
|----------|------|
| 店家名稱 | 顯示於訂購頁面 |
| 銀行代碼 | 匯款帳戶銀行代碼 |
| 銀行帳號 | 顧客匯款的帳號 |
| 戶名 | 帳戶戶名 |

### 2.2 設定取貨方式

進入後台 → **取貨方式管理** → 新增取貨方式，每種方式可設定：

| 欄位 | 說明 |
|------|------|
| 名稱 | 如「自取」、「宅配」 |
| 說明 | 取貨地點、時間、注意事項 |
| 額外費用 | 0 表示免費 |
| 允許付款方式 | 空白 = 全部允許；可限制只能現金或只能匯款 |
| 需要收貨地址 | 宅配類取貨方式請開啟此選項 |

> 建議至少建立「自取」一種取貨方式後再開始接單。

### 2.3 新增後台人員

進入後台 → **人員管理** → 新增人員，填寫 Email 後系統會寄送邀請信。人員需點擊邀請信中的連結設定密碼後才能登入。

### 2.4 設定角色與權限

系統預設兩個角色：

- **管理員**：擁有所有權限
- **助手**：可處理訂單，但不能建立開單或管理人員

如需自訂權限，進入後台 → **角色管理** → 新增角色並勾選所需權限。

### 2.5 建立第一個開單

1. 後台 → **開單管理** → 新增開單
2. 填寫開單名稱、開放時間、截止時間、每人上限
3. 進入開單詳情 → 新增商品（名稱、單價、庫存、每人商品上限）
4. 上傳商品圖片（圖庫管理）並連結至商品
5. 確認開單狀態為「啟用」

### 2.6 分享 LIFF 連結

將 LIFF 訂購連結貼至 LINE 群組，顧客點擊後即可開始訂購。

## 3. 權限與角色

### 3.1 權限列表

| 權限名稱 | 說明 | 管理員 | 助手 |
|----------|------|:------:|:----:|
| `建立開單` | 新增開單批次 | ✓ | |
| `編輯開單` | 編輯開單、商品、系統設定 | ✓ | |
| `接受訂單` | 接單（待確認 → 製作中） | ✓ | ✓ |
| `拒絕訂單` | 拒絕訂單並填寫原因 | ✓ | ✓ |
| `標記製作完成` | 製作完成（製作中 → 待付款） | ✓ | ✓ |
| `取消訂單` | 取消製作中的訂單 | ✓ | |
| `確認付款` | 確認顧客付款 | ✓ | ✓ |
| `查看報表` | 查看統計報表、匯出 CSV | ✓ | ✓ |
| `管理人員` | 新增、停用後台人員帳號 | ✓ | |
| `管理角色權限` | 新增角色、調整權限配置 | ✓ | |
| `管理取貨方式` | 新增、編輯、排序取貨方式 | ✓ | |
| `管理追加庫存排程` | 設定分批放量排程 | ✓ | |

> 管理員的「管理角色權限」無法被移除，以防止系統被鎖死。

### 3.2 帳號停用

停用帳號後，該人員所有後台操作即時被擋下，不需要更改密碼。

## 4. 後台管理功能

### 4.1 儀表板（https://ditto-cake.vercel.app/admin）

顯示**進行中**的訂單（待確認、製作中、待付款、付款確認中）。

**每張訂單卡片顯示：**
- 狀態標籤、顧客 LINE 名稱、排單號、訂單號、日期時間
- 訂購品項（每項一行）
- 操作按鈕（依當前狀態顯示）

**展開後顯示：**
- 訂購品項明細與小計
- 取貨方式、付款方式、匯款後五碼
- 訂購人、收貨人聯絡資料
- 客戶備註、店家備註（可編輯）

**操作按鈕說明：**

| 按鈕 | 出現條件 | 動作 |
|------|----------|------|
| 接單 | 待確認 | 狀態改為製作中，系統分配排單號 |
| 拒絕 | 待確認 | 需填寫原因，狀態改為已取消，自動釋放庫存 |
| 製作完成 | 製作中 | 狀態改為待付款 |
| 取消 | 製作中 | 需填寫原因，自動釋放庫存 |
| 確認收現 | 待付款（現金） | 狀態改為已完成 |
| 確認付款 | 付款確認中 | 狀態改為已完成 |

### 4.2 歷史訂單（https://ditto-cake.vercel.app/admin/orders）

查詢所有訂單，支援多條件篩選：

| 篩選條件 | 說明 |
|----------|------|
| 狀態 | 全部、各狀態單獨篩選 |
| 開單 | 指定某個開單批次 |
| 商品 | 指定某個商品 |
| 開始日期時間 | 訂單建立時間起 |
| 結束日期時間 | 訂單建立時間迄 |

點選「匯出 CSV」可下載篩選結果，格式為**一品項一行**，包含訂單號、顧客資料、商品名稱、數量、單價、小計、總金額。

### 4.3 開單管理（https://ditto-cake.vercel.app/admin/sessions）

#### 建立開單

| 欄位 | 說明 |
|------|------|
| 開單名稱 | 必填，如「5月甜點預購」 |
| 開放時間 | 選填，未填表示立即開放；未到時間顧客看到倒數計時 |
| 截止時間 | 選填，未填表示不設截止 |
| 每人上限 | 選填，同一開單每位顧客可購買總件數上限 |

#### 開單詳情

- **商品列表**：新增商品（名稱、單價、庫存、每人商品上限）、連結圖片
- **追加庫存排程**：設定未來某個時間點自動追加庫存（如分批放量）
- **統計報告**：總訂單數、各商品銷售數量、總金額（需 `查看報表` 權限）

#### 追加庫存排程

1. 點擊「新增排程」
2. 設定開放時間
3. 填入各商品追加數量（0 表示此商品本次不追加）
4. 排程到期後，顧客進入訂購頁時系統自動套用

### 4.4 圖庫管理（https://ditto-cake.vercel.app/admin/images）

- 上傳圖片至 Cloudflare R2
- 編輯圖片備註名稱
- 將圖庫圖片連結至商品（支援多張圖片、可排序）
- 刪除圖片

### 4.5 取貨方式管理（https://ditto-cake.vercel.app/admin/pickup-options）

- 新增、編輯取貨方式
- 上下架（下架後顧客訂購頁不顯示）
- 拖曳調整顯示順序

### 4.6 人員管理（https://ditto-cake.vercel.app/admin/staff）

- 新增人員 → 系統寄送邀請信
- 重新寄送邀請信
- 啟用 / 停用帳號
- 編輯人員資料、變更角色

### 4.7 角色管理（https://ditto-cake.vercel.app/admin/roles）

- 檢視現有角色的權限配置
- 新增自訂角色
- 調整角色的可用權限

## 5. 顧客端 LIFF 使用流程

### 5.1 進入訂購頁面

點擊老闆分享的 LINE LIFF 連結，系統自動以 LINE 帳號登入。

### 5.2 選擇開單

若目前有多個開單，顯示清單供選擇。若只有一個則直接進入訂購流程。若開單尚未開放，顯示**倒數計時**。

### 5.3 訂購流程（共 4 步驟）

**步驟一：選擇商品**
- 瀏覽商品名稱、價格、剩餘庫存、圖片
- 點擊 + / − 調整數量
- 限購規則：
  - 單一商品上限
  - 本次開單所有品項總件數上限

**步驟二：選擇取貨方式**
- 顯示店家設定的取貨選項
- 有額外費用會標示

**步驟三：選擇付款方式**
- 依取貨方式顯示允許的付款選項
- 銀行匯款：確認後需填匯款後五碼
- 現金付款：取貨時現場付款

**步驟四：填寫聯絡資料**
- 訂購人姓名、聯絡電話（必填）
- 收貨人資料（可勾選「同訂購人」）
- 收貨地址（宅配類取貨方式必填）
- 客戶備註（選填）

送出後訂單狀態為「待確認」。

### 5.4 查看訂單（https://ditto-cake.vercel.app/liff/status）

顯示本人的所有訂單，點擊可進入訂單詳情。

### 5.5 訂單詳情（https://ditto-cake.vercel.app/liff/orders/{id}）

| 操作 | 條件 |
|------|------|
| 修改品項 | 僅限「待確認」狀態 |
| 取消訂單 | 僅限「待確認」狀態 |
| 填匯款後五碼 | 銀行匯款且狀態為「待付款」 |
| 填客戶備註 | 任何時候 |

## 6. 訂單狀態說明

```
顧客下單
   │
   ▼
待確認 ──────────────── 老闆拒絕 ──► 已取消
   │
   │ 老闆接單（分配排單號）
   ▼
製作中 ──────────────── 老闆取消 ──► 已取消
   │
   │ 老闆標記製作完成
   ▼
待付款
   ├── 現金付款 ─── 老闆確認收現 ──► 已完成
   │
   └── 銀行匯款 ─── 顧客填後五碼
                          │
                          ▼
                    付款確認中 ─── 老闆確認 ──► 已完成
```

| 狀態 | 顧客看到 | 店家操作 |
|------|----------|----------|
| 待確認 | 等待確認中 | 接單 / 拒絕 |
| 製作中 | 製作中（顯示排單號）| 製作完成 / 取消 |
| 待付款 | 請付款（顯示金額）| 確認收現（現金）|
| 付款確認中 | 確認付款中 | 確認付款 |
| 已完成 | 訂單完成 | — |
| 已取消 | 訂單取消（含原因）| — |

## 7. 常見問題

**Q：顧客說無法開啟 LIFF 頁面？**
A：LIFF 連結必須在 LINE App 內開啟，不支援一般瀏覽器。

**Q：顧客說顯示「請透過 LINE 開啟此頁面」？**
A：確認顧客是從 LINE 內點擊連結，而非複製網址到瀏覽器。

**Q：訂單取消後庫存會恢復嗎？**
A：是，取消訂單後系統自動釋放庫存與每人購買額度。

**Q：追加庫存排程如何套用？**
A：到期後，下一位顧客進入訂購頁時系統會自動套用，不需要手動觸發。

**Q：排單號是什麼？**
A：老闆接單時由系統自動分配的號碼，用於識別製作順序，與訂單號碼不同。

**Q：訂單號碼（#0001）和排單號的差異？**
A：訂單號碼是全系統唯一的流水號（下單即產生）；排單號是接單後才分配，代表製作批次順序。
